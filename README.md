# why-you-matter.org

> A modern, calming, and deeply grounded mental health sanctuary and crisis intervention companion.

## 🌟 Key Features

- **Dynamic Reason Typing**: Zero-layout-shift comforting reasons with customizable interaction.
- **Emergency Nature & More**: 4 immersive categories (🌊 Oceans & Nature, 🐱 Cats & Purring, 🐶 Dogs & Pups, 🐾 Other Animals) with 40 curated uplifting scenes, live YouTube streams, and Web Audio synthesizer soundscapes.
- **Interactive Relief Hub**:
  - Box Breathing (4-4-4-4) visual pacer.
  - 5-4-3-2-1 Sensory Grounding.
  - Interactive Ambient Soundscapes (Rain, Ocean, Forest, Binaural 432 Hz).
  - Deep Psychological Pillars & Sublimation guidance.
- **Cosmic Thought Release**: Interactive mental burden release container that releases thoughts as stardust into the cosmos.
- **Stealth / Disguise Mode**: One-click instant disguise into a realistic corporate productivity dashboard (*WorkSpace Pro*).
- **Crisis Hotlines**: Instant regional access for Slovakia, Czechia, UK, US, and International emergency lines.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Or build for production
npm run build
npm start
```
